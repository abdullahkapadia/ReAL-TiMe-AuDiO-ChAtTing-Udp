## Day 1

My main goal is to build a real-time audio chatting application using UDP and, along the way, learn more about networking and how real-time communication actually works.
On the first day, I started with the basics. I used Go's `net` package to create a simple UDP server that listens on a specific port. I then worked on sending messages from the client to the server and receiving responses back on the client side.
It was a small start, but it helped me understand how UDP communication works and gave me a foundation to build the real-time audio chat application step by step.
